# 未採用的明天：章節記錄

只記錄已完成正文支持的事件；後續計畫在 planning，不在此預填。

## 第1章：排水口的字
- 摘要：余棠確認模型居民正以瓦字求救，發現圖外舊孔；面對醫院防洪期限，要求準備人工開閘並開始鬆動底板螺栓。
- 角色變化：余棠由清理雜物轉為查證求救，簽下異常維修原因，尚未拆板；陸衡親自用燈確認回應，提出醫院與時限風險，拿起電話準備接續；紅衣人阻止清瓦、回應燈光，指向舊孔及刻痕，姓名與身世仍未揭露。
- 伏筆進展：fs-old-drain（底板的舊水道）plant，孔及水磨痕存在，但通路未確認；fs-tally（不同深淺的刻痕）plant，尚不知含義；fs-lock-loss（拆板失去落印）plant，雙方知道代價，但底板仍貼合，尚未失準。
- 情感基調：修繕日常 → 驚疑與查證 → 兩邊生命的壓力 → 簽名承擔並開始動手

## 第2章：作廢的方案
- 摘要：拆板使落印失效；工班回報舊渠封堵、容量受限。紅衣人要求先接人，余棠答應先搭橋再拆模型棚牆，兩邊分頭準備。
- 角色變化：余棠拆下底板，接受人工開閘延遲風險，以字影回應居民並等待其搬妥工具；陸衡確認工程鎖失準，協調工班、醫院與指揮，保留人工分流；紅衣人阻止他人先破牆，寫出「先接人」，與居民拆門板搭橋。
- 伏筆進展：fs-lock-loss（拆板失去落印）resolve，潮痕散去、工程鑰匙無法轉到底；fs-old-drain（底板的舊水道）hint，模內路線露出、工班回報現實舊拱口與淤塞，尚未完成排水；fs-tally（不同深淺的刻痕）hint，紅衣人回指刻痕後堅持先接人，含義仍未揭露。
- 情感基調：不可挽回的失準 → 延誤壓力 → 找到有限出路 → 誤解與等待 → 各自付出、開始合作
